# BareVault

A turn-based roguelike in the browser, played solo. The player starts with nothing and descends level by level, equipping themselves from the vaults that guard each level's exit.

## Language

**Run**:
One attempt at descending, from the bare start until death. Death is permanent and ends the run.
_Avoid_: Game, session, playthrough

**Bare start**:
Beginning a run with no gear at all.
_Avoid_: Naked start, empty start

**Level**:
One layer of the dungeon, left only through its vault.
_Avoid_: Floor, stage, map

**Depth**:
The number of levels descended in a run; the measure of how well a run went.
_Avoid_: Score, progress

**Vault**:
The large guarded chamber at the end of every level. It holds enemies and gear, and the way down lies beyond it, so it cannot be skipped.
_Avoid_: Treasure room, boss room, dungeon room

**Gear**:
Equipment the hero obtains in vaults; the only source of equipment in a run.
_Avoid_: Loot, items, equipment

**Hero**:
The player's character, shown as `@`-style figure on the grid.
_Avoid_: Player character, avatar
